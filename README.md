# Qadam — дайындық к ҰБТ

Казахоязычный сайт для подготовки к ҰБТ по пяти предметам: Қазақстан тарихы, оқу сауаттылығы, математикалық сауаттылық, биология и химия.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Возможности

- Карта из 110 тем по пяти предметам с краткими учебными ориентирами.
- Қазақша видеоуроки с фильтрами по предметам и встроенным просмотром.
- Тематические упражнения с объяснениями и короткая диагностика по всем пяти предметам.
- Ссылка на полный пробный тест ҰТО.
- Недельный план, карточки для повторения и страница прогресса с результатами и темами для повторения.

Отмеченные темы, просмотренные уроки и результаты упражнений хранятся в браузере на текущем устройстве.

Тематические карты сверены со спецификациями [Ұлттық тестілеу орталығы](https://new.testcenter.kz/?page_id=23376). Встроенные упражнения являются учебными материалами сайта, а полный пробный тест доступен на [официальной платформе ҰТО](https://prob-ent.testcenter.kz/).
